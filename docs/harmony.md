# 어울리는 현 만들기

사용자가 그린 길이가 그대로 음높이가 됩니다. 음계나 화음에 맞추는 자동 조율은 하지 않습니다. 아래 화음은 참고 안내와 사용자가 직접 요청하는 시작용 현에만 사용합니다.

| 참고할 분위기 | 화음 | 구성음 | 시작용 현 |
| --- | --- | --- | --- |
| 차분하게 (기본) | Am | 라·도·미 | A3·C4·E4 |
| 맑게 | C | 도·미·솔 | C4·E4·G4 |
| 따뜻하게 | F | 파·라·도 | F3·A3·C4 |

선을 길게 그리면 낮게, 짧게 그리면 높게 울립니다. 음높이는 `220 × 생성 당시 화면 높이 ÷ 현 길이` Hz로 연속적으로 정해지며, 반음 사이의 미세한 음정도 그대로 보존합니다. 같은 길이는 참고할 화음을 무엇으로 고르든 같은 소리가 됩니다. 화면 높이가 720pt일 때 길이 360pt는 440Hz, 359pt는 약 441.2Hz입니다. 손을 놓아도 현의 끝점이나 음높이를 추천값에 맞추지 않습니다.

드래그할 때 손 옆에는 가장 가까운 음 이름에 ‘부근’을 붙이고 실제 주파수를 소수점 한 자리까지 표시합니다. 음 이름이 같아도 주파수는 다를 수 있습니다. 반투명 점선과 원은 선택한 화음에서 가까운 음의 **참고 길이**입니다. 실제로 만들어질 현은 손이 있는 위치까지이며, 안내에 맞추지 않아도 됩니다. ‘사용 안내’에서 ‘화음 길이 안내 표시’를 끌 수 있습니다. 이 설정은 화면의 참고선만 바꾸며 소리는 바꾸지 않습니다. 손을 놓으면 드래그 안내가 사라지고 현만 남습니다. 40pt보다 짧은 동작은 현 생성 대신 수면 탭으로 처리합니다.

화면 가장자리에서는 문구를 안쪽에 배치하고, 정확한 길이의 끝점이 화면 밖에 있으면 원을 숨깁니다. 터치 안내는 손가락 위에 표시하며 다른 손가락의 움직임이나 놓기는 첫 드래그의 안내를 바꾸지 않습니다. 안내 요소는 입력을 가로채지 않습니다. Esc·창 포커스 상실·일시정지·사용 안내 열기는 진행 중인 안내를 지웁니다. 움직임 줄이기 설정에서는 나타나고 사라지는 전환도 생략합니다.

참고할 화음 변경은 기존 현, 이후 직접 그릴 현, 재생 중인 예시 연주의 음높이에 영향을 주지 않습니다. 현의 주파수는 만들 때 한 번 정하므로 화면 크기를 바꿔도 달라지지 않습니다. 시작용 현도 생성 이후에는 다시 조율하지 않습니다.

‘어울리는 현 3개 놓기’는 수면이 비어 있을 때만 나타납니다. 사용자가 이 버튼을 누를 때만 선택한 화음의 예시 현을 만듭니다. 누르기 전에는 현이나 소리가 자동으로 만들어지지 않습니다. 좁은 화면에서는 조작 영역 위에, 낮은 가로 화면에서는 조작 영역 옆에 세 현을 배치합니다. 직접 그린 현을 대체하거나 보정하지 않습니다.

‘짧은 연주 듣기’는 현재 현의 낮은 음·중간 음·높은 음을 골라 9음을 약 5초 동안 연주합니다. 기존 현의 진동과 오디오 합성을 그대로 사용하며, 별도 녹음 파일을 재생하거나 음정을 보정하지 않습니다. 수면을 누르거나 다른 연주 버튼을 사용하면 중단합니다. 멈추기 버튼, Esc, 일시정지, 창 포커스 상실과 탭 숨김도 중단합니다. 이미 울린 음은 자연스럽게 잦아들며, 일시정지는 오디오 출력도 음소거합니다.

렌더 프레임이 늦어져도 경과 시간을 다음 음 간격에 반영합니다. 이미 지나간 음은 건너뛰고 현재 시점의 음만 연주하므로, 지연이 쌓여 예시 연주가 길어지거나 밀린 음이 한꺼번에 울리지 않습니다.

고정 화음 패널과 상단 안내문은 표시하지 않습니다. ‘사용 안내’를 열면 참고할 화음, 안내선 표시 여부, 시작용 현 배치, 짧은 예시 연주와 키보드 연주 버튼을 사용할 수 있습니다. 키보드의 ‘현 만들기’도 드래그와 같은 연속 음높이를 사용합니다. 움직임 줄이기 설정에서는 사용자가 재생을 누를 때까지 악기를 불러오지 않습니다.

구현은 `rive/strings.as`(길이에 따른 음높이), `rive/harmony.as`(시작용 화음), `rive/phrase.as`(예시 연주), `web/src/harmony.ts`(화면 문구와 참고 음 계산), `web/src/harmony.css`(사용 안내의 조작부), `web/src/drag-guide.ts`와 `drag-guide.css`(드래그 안내)에 나뉩니다. 웹이 계산한 참고 음은 오디오 엔진에 전달하지 않습니다. 구성음이나 ID를 변경할 때는 Rive와 웹 양쪽을 맞추고, 서명 빌드인 `web/public/janhyang.riv`도 갱신합니다. 빌드 방법은 [배포 문서](deployment.md)를 참고하세요.

합성기의 고정 55~2000Hz 제한도 제거했습니다. 현재는 출력 샘플레이트와 지연 버퍼가 표현할 수 있는 범위에서만 제한합니다. 이는 합성기의 기술적 한계이며 음악적 음계 보정은 아닙니다. 시각적 진동 속도의 최솟값은 소리의 주파수와 별개입니다.

검증은 `rive/harmony_test.as`에서 연속 음높이·미리보기 일치·기존 현 보존·명시적 시작용 현 배치·예시 연주를, `rive/pluck_test.as`에서 미세 음정과 기존 음역 밖의 오디오 합성을 다룹니다. `web/tests/harmony.spec.ts`는 실제 서명 파일에서 한 픽셀 이동의 음정 변화, 화음 변경과 안내선 끄기가 소리에 영향을 주지 않는지, 키보드·중단·접근성·작은 화면을 확인합니다. `web/tests/drag-guide.spec.ts`는 드래그·놓기·중단, 화면 가장자리, 두 손가락 터치와 움직임 줄이기 설정을 확인합니다. 실제 휴대폰의 첫 소리와 음색에 대한 청음 평가는 별도 확인이 필요합니다.
