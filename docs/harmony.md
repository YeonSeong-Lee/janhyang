# 어울리는 현 만들기

빈 수면에서 직접 현을 그리는 흐름을 유지하면서, 음악 이론을 몰라도 화음을 만들 수 있도록 돕습니다. 기존의 A단조 5음계 보정을 세 가지 화음의 구성음 보정으로 바꿨습니다.

| 분위기 | 화음 | 구성음 | 시작용 현 |
| --- | --- | --- | --- |
| 차분하게 (기본) | Am | 라·도·미 | A3·C4·E4 |
| 맑게 | C | 도·미·솔 | C4·E4·G4 |
| 따뜻하게 | F | 파·라·도 | F3·A3·C4 |

선을 길게 그리면 낮게, 짧게 그리면 높게 울립니다. 드래그할 때만 손 옆에 실제 엔진이 선택한 음과 짧은 안내가 나타납니다. 반투명 점선과 원은 그 음에 해당하는 길이를 보여줍니다. 손을 놓으면 안내가 사라지고 현만 남습니다. 40pt보다 짧으면 조금 더 그으라는 안내가 나오며, 손을 떼도 현을 만들지 않습니다. 음높이는 C3~A5 사이의 화음 구성음만 사용합니다. 양 끝을 임의의 Hz로 잘라 음계 밖의 음이 생기지 않도록 후보 음의 범위를 제한합니다.

화면 가장자리에서는 문구를 안쪽에 배치하고, 정확한 길이의 끝점이 화면 밖에 있으면 원을 숨깁니다. 터치 안내는 손가락 위에 표시하며 다른 손가락의 움직임이나 놓기는 첫 드래그의 안내를 바꾸지 않습니다. 안내 요소는 입력을 가로채지 않습니다. Esc·창 포커스 상실·일시정지·사용 안내 열기는 진행 중인 안내를 지웁니다. 움직임 줄이기 설정에서는 나타나고 사라지는 전환도 생략합니다.

분위기를 바꾸면 기존 현도 함께 조율합니다. 직접 그린 현은 생성 당시의 길이 비율을 보존하므로 화면을 회전하거나 분위기를 여러 번 바꿨다가 되돌려도 원래 음으로 돌아옵니다. 시작용 현은 근음·3음·5음의 역할을 유지합니다. 모양과 위치는 바꾸지 않습니다.

‘어울리는 현 3개 놓기’는 수면이 비어 있을 때만 나타납니다. 누르기 전에는 현이나 소리가 자동으로 만들어지지 않습니다. 좁은 화면에서는 조작 패널 위에, 낮은 가로 화면에서는 패널 옆에 세 현을 배치합니다. 직접 그린 현을 대체하지 않습니다.

‘짧은 연주 듣기’는 현재 현의 낮은 음·중간 음·높은 음을 골라 9음을 약 5초 동안 연주합니다. 기존 현의 진동과 오디오 합성을 그대로 사용하며, 별도 녹음 파일을 재생하지 않습니다. 수면을 누르거나 다른 연주 버튼을 사용하거나 분위기를 바꾸면 중단합니다. 멈추기 버튼, Esc, 일시정지, 창 포커스 상실과 탭 숨김도 중단합니다. 이미 울린 음은 자연스럽게 잦아들며, 일시정지는 오디오 출력도 음소거합니다.

렌더 프레임이 늦어져도 경과 시간을 다음 음 간격에 반영합니다. 이미 지나간 음은 건너뛰고 현재 시점의 음만 연주하므로, 지연이 쌓여 예시 연주가 길어지거나 밀린 음이 한꺼번에 울리지 않습니다.

고정 화음 패널과 상단 안내문은 표시하지 않습니다. ‘사용 안내’를 열면 분위기 선택, 시작용 현 배치, 짧은 자동 연주와 키보드 연주 버튼을 사용할 수 있습니다. 키보드 버튼과 드래그는 같은 현 목록을 사용합니다. 움직임 줄이기 설정에서는 사용자가 재생을 누를 때까지 악기를 불러오지 않습니다.

구현은 `rive/harmony.as`(조율), `rive/phrase.as`(예시 연주), `web/src/harmony.ts`(화면 문구), `web/src/harmony.css`(사용 안내의 조작부), `web/src/drag-guide.ts`와 `drag-guide.css`(드래그 안내)에 나뉩니다. 구성음이나 ID를 변경할 때는 Rive와 웹 양쪽을 맞추고, 서명 빌드인 `web/public/janhyang.riv`도 갱신합니다. 빌드 방법은 [배포 문서](deployment.md)를 참고하세요.

검증은 `rive/harmony_test.as`에서 음 범위·미리보기 일치·재조율·세 현 배치·예시 연주를, `web/tests/harmony.spec.ts`에서 실제 서명 파일과 웹 연결·키보드·중단·접근성·작은 화면을 다룹니다. `web/tests/drag-guide.spec.ts`는 드래그·놓기·중단, 화면 가장자리, 두 손가락 터치와 움직임 줄이기 설정을 확인합니다. 오프라인 오디오 출력에서도 9음의 신호와 정상 종료를 확인했습니다. 실제 휴대폰의 첫 소리와 음색에 대한 청음 평가는 별도 확인이 필요합니다.
