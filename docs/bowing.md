# 현 잡기와 활 연주

현 가까이에서는 손 모양 커서(`grab`)와 고리가 나타난다. 누르면 커서가
`grabbing`으로 바뀌고 고리가 좁아진다. 기본 조작은 빈 곳에서 현 그리기,
현을 당겼다 놓아 튕기기다.

**활로 켜기** 버튼은 켜짐 상태를 `aria-pressed`로 알린다. 활은 누르기 전에
가장 가까운 현에 수직으로 놓이며, 누른 동안에는 방향을 유지한다. 활과
실제 진동 중인 현의 교차점을 모두 찾아 함께 울린다. 빠른 드래그도 입력
사이의 경로를 검사한다. 활의 길이는 화면 크기에 맞춘다.

소리는 움직임의 속도에 따라 커지고, 멈추거나 놓으면 잦아든다. 현마다
위상이 유지되는 지속음을 합성하며 여러 음의 음량을 조절한다. 실제 바이올린
녹음이나 마찰음을 재현한 모델은 아니다. 현을 더 그리려면 활 모드를 끈다.

창 포커스 이탈, 포인터 취소, 일시정지, 모드 전환, 버튼으로 연주하기는
진행 중인 활 동작을 끝낸다. 추가 터치는 진행 중인 첫 포인터를 빼앗지 않는다.
오디오에도 입력 갱신 시간 제한을 두어 종료 이벤트가 누락돼도 계속 울리지 않는다.

Rive와 웹은 `scene.rml`의 `bowMode`, `cursor`, `cancelGesture`, `bowContacts`를
통해 연결된다. 기존 버튼 연주 속성 및 ID는 유지한다. 소스 변경 후에는
[배포 문서](deployment.md)의 서명 빌드 절차로 `web/public/janhyang.riv`를 갱신한다.

2026-11-17 검증: Rive 21개 테스트(활 접촉·진동·두 음의 동시 출력 및 소리 종료
포함), 웹 19개 테스트(잡기 커서·활 모드·취소·기존 접근성 및 로딩 포함), 타입
검사와 프로덕션 빌드 통과. 입력 시퀀스의 오디오를 별도 렌더링해 출력과 해제 후
무음을 확인했고, 활과 두 현의 접촉 표시를 이미지로 확인했다. 실제 모바일 기기의
터치·첫 소리 및 음색 청취 평가는 별도 수동 확인 대상이다.
