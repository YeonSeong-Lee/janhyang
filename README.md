# 잔향

[![수면에 두 현을 긋고 차례로 튕기면 파문이 번지는 연주 장면](docs/demo.gif)](https://janhyang-924.pages.dev/)

**수면에 선을 그으면 현이 됩니다.** 길게 그은 현은 낮게, 짧게 그은 현은 높게 울립니다. 현을 당겼다 놓으면 손을 뗀 자리에서 파문이 번집니다.

[소리 켜고 직접 연주하기 ↗](https://janhyang-924.pages.dev/) · [데모 영상 보기](docs/demo.mp4)

## 첫 연주

1. 빈 수면을 가로질러 선을 그으세요.
2. 그 선의 가운데를 잡아 옆으로 당겼다가 놓으세요.
3. 길이가 다른 현을 하나 더 그어 두 음을 번갈아 튕겨 보세요.

처음부터 어울리는 세 음으로 시작하고 싶다면 **시작용 현**을 놓고 **예시 연주**를 들어보세요.

## 로컬에서 실행하기

```sh
cd web
pnpm install
pnpm dev
```
