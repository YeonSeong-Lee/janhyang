# 잔향

[![빈 수면에 첫 현을 긋고 두 번 튕기는 장면](docs/demo.gif)](https://youtu.be/m9J3eBIOgbY)

**수면에 선을 그으면 현이 됩니다.** 길게 그은 현은 낮게, 짧게 그은 현은 높게 울립니다. 현을 당겼다 놓으면 손을 뗀 자리에서 파문이 번집니다.

[소리 켜고 직접 연주하기 ↗](https://janhyang-924.pages.dev/) · [YouTube에서 ‘반짝반짝 작은 별’ 연주 보기](https://youtu.be/m9J3eBIOgbY)

## 첫 연주

1. 빈 수면을 가로질러 선을 그으세요.
2. 그 선의 가운데를 잡아 옆으로 당겼다가 놓으세요.
3. 길이가 다른 현을 하나 더 그어 두 음을 번갈아 튕겨 보세요.

처음부터 어울리는 세 음으로 시작하고 싶다면 **시작용 현**을 놓고 **예시 연주**를 들어보세요.

## 언어

첫 방문에는 브라우저에서 선호하는 언어로 열립니다. 화면 아래 **文/A 언어 메뉴**에서 언어를 바꾸면 만든 현과 연주 상태가 유지되고, 다음 방문에도 선택한 언어로 열립니다. 지원하는 언어가 브라우저 목록에 없으면 영어로 시작합니다.

40개 언어를 지원합니다. 중국어는 간체와 번체, 펀자브어는 구르무키와 샤무키 문자를 따로 선택할 수 있습니다.
